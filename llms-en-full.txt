# Getting Started

LitosUI uses the [utilane](https://github.com/DvShu/utilane#readme) utility library.

## Usage

### Installation

```shell
npm install litos-ui
```

### Import and Registration

```js
import "litos-ui/styles/vars.css";
import { Button, regist } from "litos-ui";

// Register the Web Component, then use it as <l-button></l-button>.
regist(Button);
```

Import the styles and register components in your client entry point before using them on the page:

```html
<l-button type="primary">Button</l-button>
```

### Registering Components

`regist()` accepts a single component or an array of components. Component tags use the `l-` prefix followed by the component's `baseName`. For example, `Button` becomes `l-button`.

Custom component prefixes and tag names are currently unsupported; use the default `l-` tags. The library does not provide a `config()` API for setting a global prefix.

```js
import { Button, Input, regist } from "litos-ui";

regist([Button, Input]);
```

If a tag name is already registered, `regist()` skips it.

### Services and Optional Auto-imports

Services require their corresponding global styles. For example, to use Message manually:

```js
import "litos-ui/styles/message.css";
import { Message } from "litos-ui";

Message.success("Operation successful");
```

To automatically import service APIs and their styles, you can optionally use an auto-import plugin:

```shell
npm install -D unplugin-auto-import litosui-unplugin-resolver
```

Add the plugin to your Vite configuration, keeping your existing project configuration:

```js
import { defineConfig } from "vite";
import AutoImport from "unplugin-auto-import/vite";
import LitosuiResolver from "litosui-unplugin-resolver";

export default defineConfig({
  plugins: [
    AutoImport({
      resolvers: [LitosuiResolver()],
      dts: "src/auto-imports.d.ts",
    }),
  ],
});
```

Web Components still need to be registered with `regist()`.

### Global Variables

The library uses CSS variables for styling. Import the global variables stylesheet explicitly in your entry file, such as `main.ts`, to configure these values:

```js
import "litos-ui/styles/vars.css";
```

The shared source file is shown below. Its original Chinese comments are preserved:


### Dark Mode

Dark mode variables are in the separate `dark.css` file. Import it explicitly after `vars.css`, then add the `dark` class to the root element to enable dark mode. Remove the class to return to light mode. Importing `vars.css` alone does not include the dark color overrides.

```javascript
import "litos-ui/styles/dark.css";

document.documentElement.classList.add("dark");
```

## On-demand Imports

```js
import "litos-ui/styles/vars.css";
import "litos-ui/button";
import "litos-ui/input-number";
```

These client-only element entries register themselves and their configured dependencies. Import additional dependencies explicitly for conditional features; for example, Button's loading state requires `import "litos-ui/icon/loading"`. Root imports with manual `regist()` remain supported. Service subpaths, such as the default import from `litos-ui/message`, do not automatically import global styles: CSS imports in these entries are currently commented out for future Vite plugin configuration. Service APIs still require explicit calls. See [On-demand Imports](https://dvshu.github.io/litos-ui/en/on_demand.md) for the complete entry list, types, and SSR limitations.

# On-demand Imports

Import a lowercase kebab-case subpath in your client entry. Element entries register the element and its built-in dependencies. Base variables remain an explicit import.

This page describes the package built from the current source. Until a release containing these entries is published, install a local `npm pack` tarball to try them; existing npm releases may not provide these paths.

```js
import "litos-ui/styles/vars.css";
import "litos-ui/button";
import "litos-ui/input-number";
```

```html
<l-button type="primary" loading>Save</l-button> <l-input-number value="2"></l-input-number>
```

```html
  <l-button type="primary">Save</l-button>
  <l-button type="primary" loading>Saving</l-button>
  <l-input-number value="2"></l-input-number>
```

Button includes its loading icon. Parent entries such as form, tabbar, carousel and collapse include their standard child elements. Consumers import components placed in custom slots separately. Theme includes all its built-in display modes. Importing one icon, for example `litos-ui/icon/arrow-left`, registers only that icon.

Notification requires explicit registration: neither `litos-ui/notification` nor `litos-ui/notification-box` registers elements or icons.

## Classes and services

Element subpaths also provide the default class and public types. They register the same constructors exported by the root entry, so mixing subpaths with manual `regist()` calls is safe. The root entry remains available and does not automatically register components.

```js
import Button from "litos-ui/button";
import Message from "litos-ui/message";
import Notification from "litos-ui/notification";
import NotificationBox from "litos-ui/notification-box";
import { regist, InfoIcon, SuccessIcon, WarnIcon, CloseFilledIcon, CloseIcon } from "litos-ui";
regist([InfoIcon, SuccessIcon, WarnIcon, CloseFilledIcon, CloseIcon, Notification]);
import { Popover, popconfirmProps } from "litos-ui/popconfirm";

Message.success("Saved");
NotificationBox.success("Saved");
```

```ts
import type { UploadFile } from "litos-ui/upload";
import type { Column } from "litos-ui/table";
```

Service entries require explicit API calls. Their global CSS imports are currently commented out for future Vite plugin configuration; entries do not inject styles into document.head. Importing them does not open a message, create a global API variable, or scan the page. Use `litos-ui/popover` for plain Popover; `litos-ui/popconfirm` additionally registers Button and WarnIcon for the confirmation configuration. Tabs.init() and createTransition().init() remain explicit operations with cleanup.

## Styles, themes and SSR

Element Shadow DOM styles come with the entry. Components reuse module-level CSSStyleSheet instances directly. Global CSS for Message, loading, dialog, modal-box, notification, tabs, popover, select and date-picker must currently be imported explicitly through the existing styles subpaths or configured by a future Vite plugin. Import vars.css once. For dark mode, also import `litos-ui/styles/dark.css` after it and toggle the root element's `dark` class; reset, container, scrollbar and preset theme CSS remain explicit opt-ins through existing styles subpaths. Choose only one preset. No global stylesheet containing the entire library is required.

```js
import "litos-ui/styles/theme-jade.css";
document.documentElement.classList.toggle("dark");
```

These are browser modules. In SSR frameworks, import them inside a client-only entry or mounted lifecycle hook:

```js
await import("litos-ui/button");
```

Tree shaking removes unused pure exports and unrelated components. Explicit auto-registration entries are intentional side effects and remain in production bundles. Keep the package sideEffects metadata when repackaging. No auto-import plugin is required. Existing root imports and lib/styles/types subpaths remain supported.

# Style Reset

Components do not apply a style reset by default. To opt in, manually import the provided reset stylesheet in your application entry point.

For example, import it in `main.ts`:

```ts
import "litos-ui/styles/reset.css";
```

The reset stylesheet contains the following rules. This source file is shared with the Chinese documentation, so its original Chinese comments are preserved:

```css
/* 一般开发网页的时候，都是按照100%来开发 */
:where(html) {
  font-size: 62.5%;
}
:where(html, body) {
  height: 100%;
}
:where(body) {
  margin: 0;
  font-size: 14px;
  line-height: 1.6;
  -webkit-text-size-adjust: 100%;
  -webkit-tap-highlight-color: transparent;
}
/* 修复由于 inline baseline 导致的图片下方的空白间隙问题 */
:where(img) {
  vertical-align: top;
}
/* 非大面积文字排版网站通常不需要列表项，如果需要可单独设置 */
:where(ul, ol) {
  list-style: none;
  margin: 0;
  padding: 0;
}
:where(dialog) {
  border: none;
  outline: none;
  padding: 0;
  opacity: 0;
  transition: opacity 3s;
}
:where(dialog)[open] {
  opacity: 1;
}
/* 统一采用盒子模式 */
:where(div) {
  box-sizing: border-box;
}
/*
 * 去除链接默认的下划线，提高文字可读性
 */
:where(a) {
  text-decoration: none;
  color: #4998f6;
  cursor: pointer;
  transition: color 0.3s;
}
:where(a):hover {
  color: #5ba2f7; /* less tint(#4998f6, 10%) */
}
:where(a):active {
  color: #64a7f7; /* less tint(#4998f6, 15%) */
}

:where(p) {
  margin: 5px 0;
  font-size: 16px;
  line-height: 1.4;
}
```

# Utility Styles

Common CSS utility classes for transitions, animations, and scrollbars.

## 1. Transitions

### 1.1 Importing Styles

```js
import "litos-ui/styles/transition.css";
```

### 1.2 Usage

All transitions support `--l-transition-times` to control their duration, which defaults to `0.3s`. Add the corresponding `l-transition` attribute, then call `transition.init()`. See [Transition](https://dvshu.github.io/litos-ui/en/components/transition.md) for details.

### 1.3 Examples

1. `l-opacity`

Fade in and out by changing opacity.

```html
  <l-button id="toggle">Toggle</l-button>
  <span l-transition="l-opacity" class="ml-10">Hello world</span>
```

```js
  import { $one, on } from 'utilane/browser';
  //-
  on($one('#toggle'), 'click', (e) => {
    const $target = $one('[l-transition]');
    const display = $target.style.display;
    if (display === 'none') {
      $target.setAttribute('l-transition-emit', 'show');
    } else {
      $target.setAttribute('l-transition-emit', 'hide');
    }
  });
```

2. `l-fadein`

Fade in from above and reverse the effect when leaving. Use `--l-fadein-offset` to control the distance; the default is `-20px`.

```html
  <l-button id="toggle">Toggle</l-button>
  <div l-transition="l-fadein" class="ml-10 inline">Hello world</div>
  <div l-transition="l-fadein" class="ml-10 inline" style="--l-fadein-offset:-50px;">Hello world</div>
```

```js
  import { $one, on } from 'utilane/browser';
  //-
  on($one('#toggle'), 'click', (e) => {
    const $target = $one('[l-transition]');
    const display = $target.style.display;
    if (display === 'none') {
      $target.setAttribute('l-transition-emit', 'show');
    } else {
      $target.setAttribute('l-transition-emit', 'hide');
    }
  });
```

3. `l-scale`

Scale in and out.

```html
  <l-button id="toggle">Toggle</l-button>
  <div l-transition="l-scale" class="ml-10 inline">Hello world</div>
```

```js
  import { $one, on } from 'utilane/browser';
  //-
  on($one('#toggle'), 'click', (e) => {
    const $target = $one('[l-transition]');
    const display = $target.style.display;
    if (display === 'none') {
      $target.setAttribute('l-transition-emit', 'show');
    } else {
      $target.setAttribute('l-transition-emit', 'hide');
    }
  });
```

> These transition effects can also be used with Vue.

```vue
<Transition name="l-opacity">...</Transition>
```

## 2. CSS Animations

### 2.1 Importing Styles

```js
import "litos-ui/styles/animation.css";
```

### 2.2 Usage

Apply an animation by adding its CSS class or by referencing its name in the CSS `animation` property:

1. Add a CSS class.

Animation classes follow the pattern `l-` + animation name + `-anim`. For example, the rotation animation uses `l-rotate-anim`.

```html
<l-loading-icon class="l-rotate-anim"></l-loading-icon>
```

2. Reference the animation name in CSS.

Animation names follow the pattern `l-` + animation name + `-frame`. For example, the rotation animation is named `l-rotate-frame`.

```html
<l-loading-icon class="custome-rotate" />
```

```css
.custome-rotate {
  animation: l-rotate-frame 1.5s infinite linear;
}
```

The built-in animation is `rotate` (rotation).

## 3. Scrollbar Styles

Use these styles to customize the appearance of the default scrollbar.

### 3.1 Importing Styles

```js
import "litos-ui/styles/scrollbar.css";
```

### 3.2 Usage

Add the `l-scrollbar` class to the scroll container.

```html
  <div class="l-scrollbar" style="width:100%;height:80px;border:1px solid #dedede;overflow:auto;">
    <div style="width:150%;height:150px;">ScrollBar</div>
  </div>
```

### 3.3 Changing Scrollbar Colors and Size

Use the CSS variables in the table below to change the scrollbar colors and size.

```html
  <div class="l-scrollbar" style="--l-scrollbar-bg:orange;--l-scrollbar-hover:red;--l-scrollbar-size:8px;width:100%;height:80px;border:1px solid #dedede;overflow:auto;">
    <div style="width:150%;height:150px;">ScrollBar</div>
  </div>
```

### 3.4 CSS Variables

| Name | Default | Description |
| --- | --- | --- |
| `--l-scrollbar-bg` | `#d9d9d9` | Scrollbar thumb background color |
| `--l-scrollbar-hover` | `#bfbfbf` | Scrollbar thumb color on hover |
| `--l-scrollbar-size` | `10px` | Thumb size: height for horizontal scrollbars and width for vertical scrollbars |

# Preset Themes

Switch themes by overriding the CSS variables defined in `styles/vars.css`. Components inherit variables from their containing element, so they do not need to be registered or rendered again.

## Preset Themes

Seven preset themes are available: **Jade (jade, #00AA7E)**, **Coral (coral, #FF6448)**, **Tangerine (tangerine, #FF7802)**, **Apple (apple, #9E8D51)**, **Deep Sea Blue (deep-sea-blue, #1D3D79)**, **Gamboge (gamboge, #FED110)**, and **Lotus Seed (lotus-seed, #E515AA)**.

Each theme includes a primary color, color shades, status colors, and neutral colors. Control heights and border radii still use the base variables. Primary, success, error, and warning colors are configured independently; when colors are similar, the corresponding status color is adjusted to keep them distinct.

Select a card to apply its theme. Select it again to restore the default blue. Only one preset can be selected at a time, and the light or dark mode stays unchanged.

```
<button v-for="preset in presets" :key="preset.id" type="button" class="theme-preset" :style="{ '--preset-color': preset.color }" :aria-pressed="selected === preset.id" @click="selectTheme(preset.id)">
  <span class="theme-preset-swatch" aria-hidden="true"></span>
  <span class="theme-preset-name">{{ preset.name }}</span>
  <span class="theme-preset-meta">{{ preset.id }} · {{ preset.color }}</span>
  <span class="theme-preset-status">{{ selected === preset.id ? 'Selected ✓' : 'Apply theme' }}</span>
</button>
```

  <p aria-live="polite">Current theme: {{ presets.find(preset => preset.id === selected)?.name || 'Default blue' }}</p>

```
<l-button type="primary">Primary button</l-button>
<span class="theme-status" style="--status-color: var(--l-success-color); --status-bg: var(--l-success-color-light5)">Success</span>
<span class="theme-status" style="--status-color: var(--l-error-color); --status-bg: var(--l-error-color-light5)">Error</span>
<span class="theme-status" style="--status-color: var(--l-warning-color); --status-bg: var(--l-warning-color-light5, var(--vp-c-bg-soft))">Warning</span>
```

The Gamboge theme uses dark text for filled primary buttons through `--l-primary-contrast-color` (default: `#ffffff`). Its warning color uses a darker amber to distinguish it from the primary color. On light backgrounds, avoid using the bright primary color alone for small text.

## Importing Theme Variables

Import the base variables first, then choose a preset theme file. With no explicit `data-theme` selection, theme variables are applied on `:root`, and later imports override earlier ones.

```js
import "litos-ui/styles/vars.css";
import "litos-ui/styles/themes/jade.css";
// To use another preset, replace the theme import above:
// import "litos-ui/styles/themes/coral.css";
// import "litos-ui/styles/themes/tangerine.css";
// import "litos-ui/styles/themes/apple.css";
// import "litos-ui/styles/themes/deep-sea-blue.css";
// import "litos-ui/styles/themes/gamboge.css";
// import "litos-ui/styles/themes/lotus-seed.css";
```

You can also load the stylesheets directly in HTML, keeping the same order:

```html
<link rel="stylesheet" href="/path/to/litos-ui/styles/vars.css" />
<link rel="stylesheet" href="/path/to/litos-ui/styles/themes/jade.css" />
```

## Selecting a Theme with data-theme

Set `data-theme` on `html` to select a loaded `jade`, `coral`, `tangerine`, `apple`, `deep-sea-blue`, `gamboge`, or `lotus-seed` theme. An explicit selection takes precedence over the base `:root` declarations regardless of their import order. Import the theme collection before the base variables to use the default blue when no theme is selected.

```js
import "litos-ui/styles/themes.css";
import "litos-ui/styles/vars.css";

// Select Lotus Seed, or use another loaded theme
document.documentElement.dataset.theme = "lotus-seed";

// Clear the selection and restore the default colors
document.documentElement.removeAttribute("data-theme");
```

`themes.css` imports all seven presets. You can also import only the `themes/<name>.css` files you need. When `data-theme` is absent or removed, matching variables follow import order: a theme imported after `vars.css` is applied automatically; importing `vars.css` last restores the default colors. Inline color variables on the root element override theme styles, so remove existing custom inline color variables before using presets.

For dark mode, also import `litos-ui/styles/dark.css` after the base variables, then toggle the `dark` class on the root element. This file only provides dark variable overrides; it does not switch modes automatically and is not implicitly loaded by `vars.css`.

Only loaded themes can be selected with `data-theme`. Setting the identifier of a theme that has not been imported does not load its CSS automatically.

# Base

Extend `BaseComponent` to reuse Shadow DOM support, lifecycle hooks, attribute observation, batched DOM updates, and event dispatching.

## Import and Registration

```js
import { BaseComponent, regist } from "litos-ui";
```

## Basic Usage

Define a `baseName` for your custom component and register it with the default `l-` tag prefix. The example below uses version 2 rendering.

```js
import { BaseComponent, regist } from 'litos-ui';

class HelloWorld extends BaseComponent {
static baseName = 'hello-world';
constructor() {
super();
this.version = 2;
}
render_v2() {
return { template: '<span>Hello World</span>' };
}
}

regist(HelloWorld);
```

```html
<l-hello-world></l-hello-world>
```

## Properties and Methods

* `root`: The ShadowRoot when Shadow DOM is enabled; otherwise, the element itself.
* `rendered`: `true` after the base class finishes rendering and `false` after disconnection.
* `constructor(shadow = true, init = {})`: Configures whether to use Shadow DOM and accepts ShadowRootInit options.
* `render_v2()`: The version 2 rendering entry point. Returns the required `template`, `style`, and `styleSheets` fields. `template` accepts a string, HTMLElement, or DocumentFragment.
* `afterInit()`: Runs after the initial DOM is created. Access internal elements and bind events here.
* `attributeChanged(name, oldValue, newValue)`: Handles changes to attributes listed in `observedAttributes`.
* `updateDOM(changedProps)`: Updates the DOM for changed properties. Changing state does not automatically rerun `render_v2()`; implement the update logic explicitly.
* `beforeDestroy()`: Unbinds events and releases resources. The base class calls it when the component disconnects.
* `emit(name, options)`: Dispatches a CustomEvent. Both `bubbles` and `composed` default to `true`; pass event data through `options.detail`.

## Lifecycle and Usage Notes

In `connectedCallback`, the base class creates the DOM, sets `rendered`, and calls `afterInit`. On disconnection, it cancels pending updates, calls `beforeDestroy`, and clears the internal DOM. If you override either native lifecycle callback, call the corresponding `super` method.

Prefer `afterInit` and `beforeDestroy`; `initEvents` and `removeEvents` are deprecated. The base class defaults to `version = 1`, which allows older components to implement `render`. New components should set `version = 2` in the constructor and implement `render_v2`.

Component modules depend on browser APIs. In server-rendered applications, load and register them on the client. Documentation demos must also be wrapped in ClientOnly.

## On-demand entry

```js
import "litos-ui/styles/vars.css";
import BaseComponent from "litos-ui/base";
```

The base entry exports BaseComponent without registering an element.

Element entries register themselves and their configured dependencies; conditional features may require additional imports. Service and utility APIs still require explicit calls. Import from a client-only entry in SSR frameworks. See [On-demand Imports](https://dvshu.github.io/litos-ui/en/on_demand.md) for styles, child elements, types and root-entry compatibility.

# Transition

Create transitions and animations based on state changes, typically when an element or component enters or leaves the DOM.

## Import and Registration

```js
import { createTransition } from "litos-ui/lib/utils/transition.js";

// init() finds elements with l-transition and applies their transitions.
const trans = createTransition();

trans.init();
// Call trans.destroy() when the page unmounts to release observers.
```

## Examples

### Basic Usage

Create a transition handler, then call `init` after the elements have mounted. It finds elements with `l-transition`, applies their transitions, and observes changes to `l-transition-emit`. Set this attribute to `show` or `hide` to apply the corresponding transition.

To hide an element, set its `l-transition-emit` attribute to `hide`.

To remove an element after its leave transition instead of setting `display: none`, set `l-transition-method` to `remove`.

```html
  <l-button id="toggle1">Toggle</l-button>
  <p id="text1" l-transition="l-opacity" l-transition-method="hide">hello</p>
```

```css
  .l-opacity-enter-active,
  .l-opacity-leave-active {
    transition: opacity 0.3s ease;
  }
  //-
  .l-opacity-enter-from,
  .l-opacity-leave-to {
    opacity: 0;
  }
```

```js
  import { $one, on, off } from 'utilane/browser';
  import { createTransition } from 'litos-ui/lib/utils/transition.js';
  //-
  const trans = createTransition();
  // Initialize transitions for elements with l-transition.
  // Call trans.destroy() when the page unmounts.
  trans.init();
  //-
  function toggle() {
    const $text = $one('#text1');
    const transEmit = $text.getAttribute('l-transition-emit') || 'show';
    if (transEmit === 'hide') {
      $text.setAttribute('l-transition-emit', "show");
    } else {
      $text.setAttribute('l-transition-emit', "hide");
    }
  }
  //-
  on($one('#toggle1'), 'click', toggle);
```

> After using `l-transition-method="remove"`, register any newly added elements with `trans.add([element])` to observe their transitions.

### Manual Transitions

For manual control, import `transition` from `utilane/browser` and call it directly.

```html
  <l-button id="toggle2">Toggle</l-button>
  <p id="text2">hello</p>
```

```js
  function toggle2() {
    const $text = $one('#text2');
    const display = $text.style.display;
    if (display === 'none') {
      $text.style.display = 'block';
      // Apply the enter transition.
      transition($text, [['opacity', '0', '0.3s']]);
    } else {
      // Apply the leave transition.
      transition($text, [['opacity', '0', '0.3s']], 'leave', () => {
        $text.style.display = 'none';
      });
    }
  }
  //-
  on($one('#toggle2'), 'click', toggle2);
```

> `transition()` accepts four parameters:
>
> 1. `el: HTMLElement`: The element to animate.
> 2. `property: string | [string, string, string][]`: A CSS transition name, or an array of property names, values, and durations. For example, `['opacity', '0', '0.3s']` defines an opacity transition between `1` and `0` lasting `0.3s`.
> 3. `dir: 'enter' | 'leave'`: The direction: `enter` for entering and `leave` for leaving.
> 4. `finish?:() => void`: Callback invoked when the transition finishes.

### Built-in Transitions

Import `litos-ui/styles/transition.css` to apply the built-in transitions by name with the `transition` function.

```html
  <l-button id="toggle3">Toggle</l-button>
  <div class="in-trans" l-name="l-opacity">l-opacity</div>
  <div class="in-trans" l-name="l-fadein">l-fadein</div>
  <div class="in-trans" l-name="l-scale">l-scale</div>
```

```js
  import { $, $one, on, off, iterate, transition } from 'utilane/browser';
  import 'litos-ui/styles/transition.css';
  //-
  function toggleInner() {
    iterate($('.in-trans'), (item) => {
      const name = item.getAttribute('l-name');
      if (item.style.display === 'none') {
        item.style.display = 'inline-block';
        transition(item, name, 'enter');
      } else {
        transition(item, name, 'leave', () => {
          item.style.display = 'none';
        });
      }
    });
  }
  //-
  on($one('#toggle3'), 'click', toggleInner);
  // On unmount, call: off($one('#toggle3'), 'click', toggleInner);
```

## On-demand entry

```js
import "litos-ui/styles/vars.css";
import { createTransition } from "litos-ui/transition";
```

Element entries register themselves and their configured dependencies; conditional features may require additional imports. Service and utility APIs still require explicit calls. Import from a client-only entry in SSR frameworks. See [On-demand Imports](https://dvshu.github.io/litos-ui/en/on_demand.md) for styles, child elements, types and root-entry compatibility.

## API

### Transition Attributes

| Name | Description | Type | Default |
| --- | --- | --- | --- |
| `l-transition` | Transition name applied to the element | `string` | `l` |
| `l-transition-method` | How to handle the element after its leave transition | `remove` (remove the element), `hide` (hide the element) | `hide` |
| `l-transition-emit` | Applies the corresponding transition when the attribute changes | `show` (show the element), `hide` (hide the element) | `show` |

### Transition Methods

| Name | Description | Type | Default |
| --- | --- | --- | --- |
| `init` | Finds elements with l-transition and initializes their transitions | `() => void` | - |
| `destroy` | Disconnects attribute observation and releases the Observer | `() => void` | - |
| `add` | Adds elements to the transition observer | `(el: HTMLElement[]) => void` | - |

# Container

These container styles use flexbox to build common admin dashboard layouts and quickly establish a page structure:

* `l-container`: Outer container, typically a `section`. Arranges children horizontally by default; add `l-layout-vertical` for a vertical layout. Containers can be nested.
* `l-header`: Header container, typically a `header`.
* `l-aside`: Sidebar container, typically an `aside`.
* `l-main`: Main content container, typically a `main`.
* `l-footer`: Footer container, typically a `footer`.

These layouts are commonly used for admin dashboard home pages.

## Imports

These styles are not packaged as a custom element. Import the stylesheet manually when needed.

```ts
import "litos-ui/styles/container.css";
```

## Common Layouts

```html
  </section>
```

```html

    <aside class="l-aside">Aside</aside>
```

# Theme

Switch themes for more comfortable viewing during extended screen use.

## Import and Registration

```js
import "litos-ui/styles/vars.css";
import "litos-ui/styles/dark.css";

  Theme,
  ThemeColor,
  regist,
  Button,
  SelectOri,
  Switch,
  Radio,
  RadioGroup,

  SunIcon,
  MoonIcon,
  ThemeDefaultIcon,
} from "litos-ui";

// Register the dependencies for the selected style.

regist(SelectOri); // Select style
regist([Switch, SunIcon, MoonIcon]); // Switch style
// Radio group with icons [label="icon"]

```



### Custom Styles

The built-in theme switchers provide different layouts around the theme functions in `utilane`.

The commonly used functions are `getTheme()` and `applyTheme()`.

The built-in switching effect is a fade transition.

You can create your own layout or animation. The example below uses `Radio` with text labels. Its circular animation requires the View Transitions API.

```html
  <l-radio-group gap="15" id="customThemeRadio">
    <l-radio value="auto">System</l-radio>
    <l-radio value="light">Light</l-radio>
    <l-radio value="dark">Dark</l-radio>
  </l-radio-group>
```

```js
  import { applyTheme } from "utilane/browser";
  //-
  const $radio = document.querySelector('#customThemeRadio');
  //-
  $radio.addEventListener('change', (e) => {
    const newTheme = e.target.value;
    const transition = document.startViewTransition(() => {
      // Apply the theme.
      applyTheme(newTheme, true, false).then();
    });
    //-
    transition.ready.then(() => {
      /*
        For a circular reveal centered on the pointer in a click handler:
        // Get the pointer coordinates.
        const { clientX, clientY } = e;
        a: (clientX, clientY)
                              b: (innerWidth, innerHeight)
        The distance from a to b is the maximum radius.
        //-
        // Calculate the maximum radius.
        const radius = Math.hypot(
          Math.max(clientX, innerWidth - clientX),
          Math.max(clientY, innerHeight - clientY)
        );
      */
      //-
      // Start the circular reveal.
      document.documentElement.animate(
        /*
          // Expand from the pointer position.
          clipPath: [
             `circle(0% at ${clientX}px ${clientY}px)`,
             `circle(${radius}px at ${clientX}px ${clientY}px)`,
          ]
        */
        {
          clipPath: [`circle(0% at center)`, `circle(100% at center)`],
        },
        // Set the duration and target pseudo-element.
        {
          duration: 300,
          pseudoElement: "::view-transition-new(root)",
        }
      );
    });
  });
```

```css
  ::view-transition-new(root),
  ::view-transition-old(root) {
    /* Disable the default animation. */
    animation: none;
  }
```

### Color Generation Utility

```text
generateButtonColor(color: string, text?: boolean, ghost?: boolean): ButtonColor
```

Generates nine CSS variables for normal, text, or ghost buttons from a base color (the text/background/border variables in the table below and their hover and active variants). The function does not modify buttons or the DOM; color adjustments run only when you explicitly call it.

| Parameter | Type | Description | Default |
| --- | --- | --- | --- |
| `color` | `string` | Required base color, using a color string supported by `adjust`, such as `"#00AA7E"`; an empty string returns an empty object | Not set |
| `text` | `boolean` | Whether to generate text button colors; the background and border are transparent, and the text color changes on hover and active states | `false` |
| `ghost` | `boolean` | Whether to generate ghost button colors; the background is transparent, and the text and border colors change on hover and active states | `false` |

When both `text` and `ghost` are `true`, text button colors take precedence and the border is transparent. These parameters only control the generated result; they do not set the button’s `text` / `ghost` attributes. Keep the button attributes consistent with the generation parameters.

**Returns:** `ButtonColor`, a new color variable object that can be assigned to `button.color` or passed to `button.setColor()`. A non-empty color generates nine variables; an empty string generates `{}`. The result is a static snapshot and is not automatically recalculated when the button’s attributes change.

`ButtonColor` is a mapping of these CSS variables to optional string values and also supports overriding only some variables. Import the type with `import type { ButtonColor } from "litos-ui/utils"` or from the root entry.

# Input

## Import and Registration

```js
import { Input, regist, CloseFilledIcon } from "litos-ui";

regist(Input);
regist(CloseFilledIcon); // Required for clearable inputs.
```

## Examples

### Basic Usage

A basic text input.

```html
  <l-input placeholder="Enter text"></l-input>
```

### Disabled State

Set `disabled` to disable the input.

```html
  <l-input placeholder="Enter text" disabled></l-input>
```

### Read-only State

Set `readonly` to make the input read-only. Users can still focus it and select or copy text, but the clear button is hidden. Use `readonly` or `readonly="true"` to enable it; set `readonly="false"` or remove the attribute to restore editing. You can also toggle the instance’s boolean `readOnly` property dynamically. Programmatic changes to `value` remain available. Native input read-only restrictions apply to types such as text and number, but not to types such as checkbox or range that do not support read-only behavior.

```html
  <l-input value="Read-only text you can select and copy" readonly clearable></l-input>
```

```js
const input = document.querySelector("l-input");
input.readOnly = true;
input.readOnly = false;
// Alternatively, use setAttribute("readonly", "") / removeAttribute("readonly").
```

### Restricting Input

The current implementation does not support `allow-input` or `autofocus`. Use `setParser()` to restrict input, as shown below. Call `focus()` after mounting to focus the input.

### Input Parser

Use `setParser` to parse incoming values with a custom function, for example to accept only non-negative integers.

```html
  <l-input id="input-parser-example" placeholder="Enter a non-negative integer" clearable></l-input>
```

```ts
  function numericParse(value) {
    let val = parseInt(value, 10)
    if (Number.isNaN(val)) {
      val = ''
    } else {
      val = Math.abs(val)
    }
    return String(val);
  }
  //-
  const $input = document.querySelector('l-input#input-parser-example');
  $input.setParser(numericParse);
```

### Input with Icons

```js
import { ReductionIcon, SearchIcon, regist } from "litos-ui";

```

Use the `prefix` and `suffix` slots to add icons.

```html
  <l-input placeholder="input something">
    <l-reduction-icon slot="prefix"></l-reduction-icon>
    <l-search-icon slot="suffix"></l-search-icon>
  </l-input>
```

# Select

* Show a dropdown menu as an alternative to a native select, including support for multiple selection.
* Use a dropdown when there are too many options to display at once.

> The default width of `l-select` is `100%`. Set an explicit width when using it inline.

## Import and Registration

```js
import {
  regist,
  Select,
  ArrowDownIcon,
  Tag,
  CloseIcon,
  LoadingIcon,
  CloseFilledIcon,
} from "litos-ui";
import "litos-ui/styles/select.css";

regist([ArrowDownIcon, Select]);
// multiple
regist([Tag, CloseIcon]);
// loading
regist([LoadingIcon]);
// clearable
regist([CloseFilledIcon]);
```

## Examples

### Basic Usage

Supply options with `setOptions()`. Read or update the selection through `.value`; use an array for multiple selection.

```html
  <l-select empty-text="No options" placeholder="Select an option" id="select1"></l-select>
```

```js
  const $select1 = document.querySelector('#select1');
  $select1.setOptions([{value:0,label:'Apple'}, {value:1,label:'Banana'}]);
  // Multiple selection: $select1.value = [0, 1];
  $select1.value = 0;
```

> 1. Use `value-field` and `label-field` to customize the option keys for values and labels.
> 2. String selections can also be provided through the HTML `value` attribute; separate multiple values with `,`.

### Disabled State

Set `disabled` to disable the selector.

```html
  <l-select empty-text="No options" placeholder="Select an option" disabled></l-select>
```

Set `disabled: true` on an option object to prevent users from selecting it from the dropdown.

### Multiple Selection

Enable `multiple` for multiple selection. Selected values are shown as Tag components by default; enable `collapse-tags` to show them as text instead.

In multiple mode, the `value` property is an array. Native `FormData` includes one entry per value under the same field name. Selecting an option, removing a tag, or clearing the selection fires `change`.

```html
  <l-select empty-text="No options" placeholder="Select an option" multiple width="180px"></l-select>
  <l-select empty-text="No options" placeholder="Select an option" multiple collapse-tags width="180px"></l-select>
```

### Clearable Selection

Enable `clearable` to let users clear the selection.

```html
  <l-select empty-text="No options" placeholder="Select an option" clearable width="180px"></l-select>
  <l-select empty-text="No options" placeholder="Select an option" multiple collapse-tags clearable width="180px"></l-select>
```

### Filtering Options

Filter options to find them quickly.

Enable `filterable` to search options. By default, Select matches labels containing the input. Call `setFilter()` with a custom function to change this behavior. The function receives the search string and option, and returns a boolean indicating whether the option matches.

```html
  <l-select empty-text="No options" placeholder="Select an option" filterable width="180px"></l-select>
  <l-select empty-text="No options" placeholder="Select an option" id="select2" multiple filterable width="180px"></l-select>
```

```js
  const $select2 = document.querySelector('#select2');
  $select2.setOptions([{value:0,label:'Apple'}, {value:1,label:'Banana'}]);
  //-
  function filter(match, option) {
    return option.label.includes(match) || option.value == match;
  }
  //-
  $select2.setFilter(filter);
```

### Remote Search

Search remote data by entering keywords.

Enable both `filterable` and `remote`, then handle `search` using `event.detail.value`. Fetch matching data and call `setOptions()` to replace the options. Set `loading` while the request is pending.

```html
  <l-select empty-text="No options" placeholder="Select an option" id="select3" multiple filterable remote width="180px"></l-select>
```

```js
  const fruits = ["Apple", "Banana", "Orange", "Grape", "Lemon", "Strawberry", "Cherry", "Mango", "Kiwifruit", "Bayberry", "Pineapple", "Watermelon", "Hami melon", "Peach", "Pear", "Persimmon", "Durian", "Coconut", "Longan", "Lychee"];
  const $select = document.querySelector('#select3');
  //-
  function handleSearch(e) {
    const $target = e.target;
    if ($target.loading) return;
    $target.loading = true;
    // You can also set loading through an attribute.
    // $target.setAttribute('loading', 'on');
    const searchValue = e.detail.value;
    // Simulate a request.
    setTimeout(() => {
      const options = fruits.filter((item) => {
        return item.includes(searchValue);
      }).map((item, index) => {
        return { value: index, label: item }
      });
      $target.setOptions(options);
      $target.loading = false;
      // $target.setAttribute('loading', 'off');
    }, 1500);
  }
  //-
  $select.addEventListener('search', handleSearch);
  // $select.removeEventListener('search', handleSearch);
```

# Form

A form with field management, data entry, validation, reset behavior, and layout styles.

## Import and Registration

```js
import { Button, Form, FormItem, Input, Space, regist } from "litos-ui";

regist([FormItem, Form, Input, Button, Space]);
```

## Examples

### Basic Usage

A basic form with layout, default values, validation, reset, and submission. Validation uses [utilane/validator](https://github.com/DvShu/utilane#readme).

Editing a field validates it and any fields that depend on it. Submission validates the entire form. A failed business rule sets the field's `validity.customError` to `true`.

```html
  <l-form id="lform">
    <l-form-item required label="Name" prop="name">
      <l-input placeholder="Enter your name" value=""></l-input>
    </l-form-item>
    <l-form-item required label="Password" prop="password">
      <l-input placeholder="Enter your password" type="password" value=""></l-input>
    </l-form-item>
    <l-form-item required label="Confirm password" verify="same:password" prop="confimPassword">
      <l-input placeholder="Enter your password again" type="password" value=""></l-input>
    </l-form-item>
    <l-form-item label="">
      <l-space>
        <l-button html-type="reset">Reset</l-button>
        <l-button html-type="submit" type="primary">Submit</l-button>
      </l-space>
    </l-form-item>
  </l-form>
```

> 1. Use the Space component to add spacing between buttons.
> 2. Inside Form, a Button with `html-type="reset"` or `html-type="submit"` triggers form reset or submission.

Use the `value` attribute or `defaultValue` property to set the value restored on reset. For composite fields such as arrays, use the control's `defaultValue`. Once the current value has changed, updating the default preserves the current edit until the next reset. The first assignment to the `value` property only sets the current value.

Press Enter in a single-line `l-input` to activate the form's first submit button.

### Native Forms

`l-button` can submit or reset a native `<form>`. Pressing Enter in a single-line `l-input` can also activate its submit button.

Standalone `l-form` skips browser constraint validation on submit and runs its business validation. When it sits inside a native `<form>`, the browser checks constraints according to that form's `novalidate` attribute and the submit button's `formnovalidate` attribute. The `l-form` that starts submission runs its own business rules. The browser handles submissions from the outer form's own buttons.

```html
  <form id="nativeButtonForm">
    <l-input name="username" placeholder="Username" aria-label="Username" required></l-input>
    <l-button html-type="submit" type="primary">Submit</l-button>
    <l-button html-type="reset">Reset</l-button>
    <output aria-live="polite"></output>
  </form>
```

### Form-wide Autofill

Form's `autocomplete` supplies a default for supported controls and native `input`, `textarea`, and `select` elements within the form. Change the default below to see the fields inherit it while the email field keeps its own `email` hint.

Register `SelectOri` and `MdInput` alongside the basic form components to use this example.

```html
  <l-select-ori id="formAutocompleteMode" value="on" aria-label="Default autofill setting">
    <option value="on">Allow autofill</option>
    <option value="off">Turn off autofill hints</option>
  </l-select-ori>
  <l-form id="autocompleteForm" autocomplete="on">
    <l-form-item label="Name">
      <l-input name="name" placeholder="Inherits the form setting"></l-input>
    </l-form-item>
    <l-form-item label="Phone">
      <l-md-input name="tel" html-type="tel" label="Inherits the form setting"></l-md-input>
    </l-form-item>
    <l-form-item label="Email">
      <l-input name="email" type="email" autocomplete="email" placeholder="Uses its own email hint"></l-input>
    </l-form-item>
  </l-form>
```

```js
  const mode = document.querySelector('#formAutocompleteMode');
  mode.addEventListener('change', () => {
    document.querySelector('#autocompleteForm').autocomplete = mode.value;
  });
```

Remove a field's `autocomplete` attribute to restore inheritance. When Form leaves it unset, it uses the setting from the surrounding native form, if available. The browser controls whether to offer autofill. Password managers can still fill fields with `off`, and autofill applies only to controls that already support it.

### Localized Validation

The example defaults to English and retains Chinese messages under the `zh` key to demonstrate language switching. This translates validation messages supplied by the page; it does not change built-in component messages.

```js
import { Radio, RadioGroup, regist } from "litos-ui";
regist([Radio, RadioGroup]);
```

Configure custom validation rules with `setSchemas()` to provide localized messages. Enable `emit-error` to receive validation failures through `validate-error`, translate the error identifiers, then pass the messages to `setErrors()`.

```html
  <div>
    <l-radio-group value="en" id="langCheck">
      <l-radio label="Chinese" value="zh" button></l-radio>
      <l-radio label="En" value="en" button></l-radio>
    </l-radio-group>
    <hr/>
    <l-form id="i18nForm" emit-error>
      <l-form-item required label="Mobile number" prop="mobile">
        <l-input placeholder="Enter your mobile number"></l-input>
      </l-form-item>
      <l-form-item required label="Password" prop="password">
        <l-input placeholder="Enter your password" type="password"></l-input>
      </l-form-item>
      <l-form-item label="">
        <l-button type="primary" html-type="submit">Submit</l-button>
      </l-form-item>
    </l-form>
  </div>
```

```ts
  import { $one, on } from 'utilane/browser';
  //-
  let $i18nForm, $langCheck;
  let lang = 'en';
  let errors = {};
  const i18n = {
    zh: {
      mobile_required: '手机号不能为空',
      mobile_invalid: '请输入正确的手机号码',
      password_required: '密码不能为空',
      password_min6: '密码至少为6位',
      password_invalid: '密码必须包含字母和数字'
    },
    en: {
      mobile_required: 'Mobile is required',
      mobile_invalid: 'Please enter a valid mobile number',
      password_required: 'Password is required',
      password_min6: 'Password must be at least 6 characters',
      password_invalid: 'Password must contain letters and numbers'
    }
  }
  //-
  function handleI18nSubmit(event) {
    const $target = event.target;
    errors = {};
    console.log($target.getData());
  }
  //-
  function setI18nErrors() {
    const showErrors = {};
    for (const key in errors) {
      const errorMessage = errors[key];
      if (errorMessage) {
        if (errorMessage in i18n[lang]) {
          showErrors[key] = i18n[lang][errorMessage];
        } else {
          showErrors[key] = errorMessage;
        }
      }
    }
    $i18nForm.setErrors(showErrors);
  }
  //-
  function handleI18nError(event) {
    const { errors: nextErrors, all } = event.detail;
    errors = all === true ? nextErrors : { ...errors, ...nextErrors };
    setI18nErrors();
  }
  //-
  function handleLangChange(e) {
    lang = e.detail.value;
    if (Object.keys(errors).length) {
      setI18nErrors(errors);
    }
  }
  $i18nForm = $one('#i18nForm');
  $langCheck = $one("#langCheck");
  $i18nForm.setSchemas([{
    key: 'mobile',
    rules: [
      { rule: 'required', message: 'mobile_required' },
      { rule: 'mobile', message: 'mobile_invalid' },
  ]}, {
    key: 'password',
    rules: [
      { rule: 'required', message: 'password_required' },
      { rule: (v) => v.length >= 6, message: 'password_min6' },
      { rule: /^(?=.*[0-9])(?=.*[a-zA-Z])([a-zA-Z0-9]{6,15})$/, message: 'password_invalid' }
    ]
  }]);
  on($i18nForm, 'validate-error', handleI18nError);
  on($i18nForm, 'submit', handleI18nSubmit);
  on($langCheck, 'change', handleLangChange);
```

> Each schema key must match the field's `name`. If the control inherits its name from FormItem, use that item's `prop`.
> Use unique message identifiers in the rules so they can be mapped to localized error messages.

### Form Methods

Custom rule functions return a boolean synchronously. Returning a Promise causes the field to fail validation. Call `validateField()` to revalidate specific fields after setting a value in code.

`getData()` reads the current values of associated fields synchronously. You can read them immediately after assigning a value or from an `input` or `change` handler. It includes disabled fields, keeps their original business values, and uses the last control in DOM order when several share a name. Each call returns a new top-level object and preserves references to field values.

Native checkboxes return booleans, radio buttons return the selected value, and multiple selects return string arrays. File inputs return `File`, `File[]`, or `null`. Other text inputs return strings. To associate a control outside a standalone `l-form`, set its `form` attribute to `lForm.nativeForm.id`. Both elements must be in the same DOM tree. When multiple `l-form` elements share a surrounding native form, each `getData()` call reads its own controls.

| Method | Description | Type |
| --- | --- | --- |
| `validate` | Validates all data and returns a Promise with the result | `() => Promise<{ result: boolean; errors: Record<string, any> }>` |
| `getData` | Returns a shallow snapshot of the current field values | `() => Record<string, any>` |
| `validateField` | Validates the specified fields. Resolves on success and rejects with field errors in `error.detail` on failure | `(field: string \| string[]) => Promise<void>` |
| `clearValidate` | Clears displayed errors and interaction state while preserving field validity | `() => void` |
| `reset` | Triggers a reset on the associated native form. If the reset proceeds, defaults are restored and error messages are cleared. Other controls that share the form also reset | `() => void` |
| `submit` | Runs business validation and emits `submit` on success. With `novalidate`, it skips automatic business validation | `() => void` |
| `setErrors` | Replaces the displayed errors. Omit entries for valid fields or set them to `undefined` or `null`. Pass `{}` to clear all displayed errors | `(errors: Record<string, any>) => void` |
| `setValidateErrors` | With `emit-error`, emits `validate-error` with `errors` and `all`. Otherwise behaves like `setErrors()`. `all` defaults to `true` | `(errors: Record<string, string \| undefined>, all?: string \| string[] \| boolean) => void` |
| `setSchemas` | Replaces the entire set of validation rules | `(schemas: SchemaType[]) => void` |
| `setSchema` | Replaces the validation rules for the specified `key` and keeps other fields' rules | `(schema: SchemaType) => void` |
| `addSchemas` | Appends rules for multiple fields. Rules for the same `key` are cumulative | `(schemas: SchemaType[]) => void` |
| `addSchema` | Appends rules for one field. Rules for the same `key` are cumulative | `(schema: SchemaType) => void` |

| `key` | Field name matching the control's `name` or FormItem's `prop` | `string` | Required |
| `required` | Enables required validation | `boolean` | `false` |
| `rules` | Validation rules in execution order | `RuleType[]` | `[]` |
| `message` | Error message used when a rule provides none | `string` | Validator's default message |

### FormItem Attributes

| Name | Description | Type | Default |
| --- | --- | --- | --- |
| `label` | Label text | `string` | - |
| `verify` | Built-in rules: required, same:password (password confirmation), and mobile (phone number) | `string` | - |

The default text list uses `CloseIcon`. The failure state in `picture` mode uses `PictureIcon`. ### Custom Response Parsing

Set the JavaScript property `parseResponse` to provide a response parser.

```html
<l-upload accept="image/*" list-type="picture" action="http://127.0.0.1:3001/upload" data-response-parser="local">
  <l-plus-icon></l-plus-icon>
</l-upload>
```

```js
function parseLocalUploadResponse(response) {
  if (response?.status !== "success" || typeof response?.data?.url !== "string") {
    throw new Error("The upload response does not contain a valid file URL");
  }
  const url = new URL(response.data.url);
  if (url.origin !== "http://127.0.0.1:3001" || url.username || url.password) {
    throw new Error("The file URL is not from the allowed local upload service");
  }
  return url.href;
}
//-
const upload = document.querySelector("l-upload[data-response-parser=local]");
upload.parseResponse = parseLocalUploadResponse;
```

Return the file URL from `parseResponse` when parsing succeeds. Use `throw` to report a parsing failure.

### Custom Upload

Use the `customRequest` property to replace the default request function. When a custom function is provided, `action` is optional: the function can choose its own URL or use a service SDK. An asynchronous function returns `Promise<UploadRequestResult>` containing `response` and optional `responseText` and `status` fields. The component then calls `parseResponse` and handles success, failure, and URL validation. See "customRequest Return Value" in the API section for the full field descriptions.

`body` already contains the `file` and `data` form fields. Let the browser generate the multipart Content-Type and boundary. An SDK can access `options.file.raw`. Report actual upload progress with `options.onProgress(percent)`, using a value from 0 to 100. If progress is not reported, the component shows an indeterminate animation. It enters the parsing phase when the request completes.

```html
<l-upload id="upload-custom-request" accept="image/*" list-type="picture">
  <l-plus-icon></l-plus-icon>
</l-upload>
```

```js
async function demoCustomRequest({ body, headers, signal, onProgress }) {
  signal.throwIfAborted();
  let percent = 0;
  let timer;
  const stopProgress = () => { clearInterval(timer); };
  try {
    // Simulated progress for this example only; it does not measure bytes uploaded by fetch.
    onProgress(percent);
    timer = setInterval(() => {
      percent = Math.min(percent + 10, 90);
      onProgress(percent);
    }, 150);
    signal.addEventListener("abort", stopProgress, { once: true });
    // The component has already added the file and extra fields to body.
    const result = await fetch("http://127.0.0.1:3001/upload", {
      method: "POST", body, headers, signal,
    });
    const responseText = await result.text();
    const response = JSON.parse(responseText);
    signal.throwIfAborted();
    if (result.ok) onProgress(100);
    return { response, responseText, status: result.status };
  } finally {
    stopProgress();
    signal.removeEventListener("abort", stopProgress);
  }
}
//-
const upload = document.querySelector("#upload-custom-request");
upload.customRequest = demoCustomRequest;
```

### Managing fileList Externally

```js
function demoFileList(upload) {
  upload.fileList = [
    { id: "first", url: "http://127.0.0.1:3001/files/3b315d19-d97b-47a9-96bf-724a9aa9da11.jpeg", status: "uploading", percentage: 0 },
    { id: "second", url: "http://127.0.0.1:3001/files/5a710bd6-c7e5-4b7b-8e99-5a37ccf92efd", status: "ready" },

  const patch = (id, changes) => {
    upload.fileList = upload.fileList.map((file) => file.id === id ? { ...file, ...changes } : file);

      patch("first", { status: "success", percentage: 100 });
      patch("second", { status: "uploading", percentage: 0 });
    }, 3000),
    setTimeout(() => patch("second", { status: "fail" }), 5000),
  ];
  // Call when the page unmounts or the example is rebuilt to stop further updates.

}
```

### Request Headers and Extra Fields

Use `headers` to set upload request headers and `data` to add form fields submitted with the file. Both accept a valid JSON object in an HTML attribute or a plain object assigned to the corresponding JavaScript property. Header names must be valid HTTP header names, and values must be strings without null characters, carriage returns, or line feeds. Values in `data` can be strings, finite numbers, or booleans and are converted to strings when submitted. Use double quotes inside JSON. Let the browser generate the multipart `Content-Type` and boundary.

```html
<l-upload
  action="http://127.0.0.1:3001/upload"
  headers='{"X-Token": "Bearer token"}'
  data='{"source": "litos-ui-docs", "type": "file"}'
>
  <l-button type="primary">Select files</l-button>
</l-upload>
```

You can also set these values on the component instance:

```js
const upload = document.querySelector("l-upload");
upload.headers = { "X-Token": "Bearer token" };
upload.data = { source: "litos-ui-docs", type: "file" };
```

The local test service returns the extra fields in `data.fields` in its response.

### Using Upload with Forms

Read upload progress, pending `raw` files, and results through `fileList` or the upload events. Both `l-form.getData()` and native `FormData` omit the file list. Resetting the form leaves the list intact. To save attachments with a submission, read entries with `status` set to `success` or use the data from the `success` event.

### Upload Attributes

| Name | Description | Type | Default |
| --- | --- | --- | --- |
| `accept` | Allowed types for newly selected and dropped files. Supports comma-separated extensions, MIME types, and wildcards, such as `.png,image/jpeg,image/*`. | `string` | - |
| `multiple` | Allows selecting and appending multiple files in text and picture-card modes. Picture mode always keeps one file and replaces it on selection. | `boolean` | `false` |
| `disabled` | Disables file selection, dropping files, and list actions. Can be changed at runtime. | `boolean` | `false` |
| `drag` | Enables drag-and-drop upload. | `boolean` | `false` |
| `list-type` | Display mode: `text` (file list), `picture` (a single image in the trigger, replaced on selection), or `picture-card` (an image gallery). | `string` | `text` |
| `max-size` | Maximum file size in KB, as a non-negative finite number. Files exceeding it are not added to the list. | `number` | `0` (unlimited) |
| `max-count` | Maximum total file count, as a non-negative safe integer. The picture-card trigger is hidden when the limit is reached. Picture mode keeps one file and allows replacement. | `number` | `0` (unlimited) |
| `auto-upload` | Uploads automatically. Set to `false` to start uploads manually with `upload()`. | `boolean` | `true` |
| `action` | URL for the default XHR upload, submitted as multipart/form-data with the file field named file. Optional with customRequest. | `string` | - |
| `show-file-list` | Shows the list in text and picture-card modes. Picture mode always hides the list while keeping its image preview. | `boolean` | `true` |
| `headers` | Request headers as a JSON object with string values in an HTML attribute, or a plain object assigned through the property. | `object` | `{}` |
| `data` | Extra form fields as a JSON object with string, finite-number, or boolean values in an HTML attribute, or a plain object assigned through the property. | `object` | `{}` |
| `with-credentials` | Includes cookies with the built-in XHR request. Configure credentials separately in customRequest. | `boolean` | `false` |
| `timeout` | Timeout per upload request in milliseconds. Must be a non-negative safe integer no greater than `2147483647`. Applies to both built-in XHR and customRequest. | `number` | `0` (unlimited) |

Extension rules in `accept` match the file name, while MIME rules match `File.type`. Invalid rules are ignored; if no valid rules are provided, all types are allowed. Rejected files fire `error` and do not count toward the file limit. Client-side validation provides interaction feedback; the server must independently validate file types and content.

Invalid numeric HTML attributes for `max-size`, `max-count`, and `timeout` fall back to `0`. Invalid JSON or object shapes for `headers` and `data` fall back to `{}`. Assigning invalid values through the corresponding JavaScript properties throws a `TypeError`.

`timeout` covers only the upload request phase. Timing stops when the response is received and does not include `parseResponse` execution. A timeout fires an upload-phase `error` and aborts `signal`. A custom request must pass this signal to `fetch` or its SDK to stop the external request.

| `timeout` | Upload timeout in milliseconds. A non-negative safe integer no greater than `2147483647`. | `number` | `0` |

| --- | --- |

#### customRequest Return Value

An asynchronous upload function returns `Promise<UploadRequestResult>`. With `async`, `return { response, responseText, status }` is automatically wrapped in a Promise. The component waits for that Promise to resolve before calling `parseResponse`.

```text
(options: UploadRequestOptions) => Promise<UploadRequestResult>

UploadRequestResult = {
  response: unknown;
  responseText?: string;
  status?: number;
}
```

The returned object has the following fields:

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `response` | `unknown` | Yes | Not set | Response data passed as the first argument to `parseResponse(response, context)`, usually a parsed JSON object. This field is required; returning only an image URL or a fetch Response object does not satisfy the result format. |
| `responseText` | `string` | No | `""` | Raw response text, passed as `context.responseText` to the parser and as `event.detail.response` in the success event. The component does not derive `response` from it or serialize `response` for you. |
| `status` | `number` | No | `200` | HTTP status code. Pass the actual request status, such as fetch's `result.status`. It must be an integer from 0 to 599. Only 200–299 proceed to response parsing; other values cause an upload failure. This is separate from the file status string in fileList. |

The structure of `response` depends on your API, for example `{ url: "/files/photo.png" }`. The default parser reads `url`, `data.url`, or `link`; use `parseResponse` for other structures. The success event preserves the response data in `event.detail.data`. Return the image URL from the parser; an extra top-level `url` field in `UploadRequestResult` is not required.

For network or application-level failures, use `throw new Error("Upload failed")` or return a rejected Promise. The component enters the failure state and fires `error`. HTTP errors can also be reported through the actual `status`; `fetch` does not automatically reject its Promise for 4xx or 5xx responses. Report progress separately through `options.onProgress(percent)`, rather than in the result object.

# List

A list that loads more data as you scroll to the bottom.

## Import and Registration

```js
import { List, regist, LoadingIcon } from "litos-ui";

regist([List, LoadingIcon]);
```

## Examples

### Basic Usage

Scrolling to the bottom emits a `load` event. Set `finish` when all data has been loaded.

```html
  <div style="height:300px">
    <l-list id="list"></l-list>
  </div>
```

```js
  const $list = document.querySelector('#list');
  // Simulate paginated data.
  let start = 0;
  let max = 20;
  let step = 10;
  //-
  function handleLoadmore() {
     // Simulate data loading.
    setTimeout(() => {
      if ($list && start < max) {
        let isFinish = false;
        let end = start + step;
        if (start + step >= max) {
          isFinish = true;
          end = max;
        }
        $list.append(createRenderFragemnt(start, end));
        $list.removeAttribute('loading');
        if (isFinish) {
          $list.setAttribute('finish', 'finish');
        } else {
          $list.removeAttribute('finish');
        }
        start = end;
      }
    }, 1000);
  }
  //-
  function createRenderFragemnt(start, end) {
    const fragment = document.createDocumentFragment();
    for (let i = start; i < end; i++) {
      const $div = document.createElement('div');
      $div.style.cssText = 'padding: 10px; border-bottom: 1px solid #dedede;';
      $div.textContent = i;
      fragment.appendChild($div);
    }
    return fragment;
  }
  //-
  // Listen for the load event.
  $list.addEventListener('load', handleLoadmore);
```


Show a loading indicator over a region while its data is being loaded.

```html
  </div>
```

```html
  LLoading.init();
```

Add `l-loading-fullscreen` to mount the overlay on `body` and display a fullscreen indicator. Scrolling is locked by default; set `l-loading-lock="false"` to allow scrolling.

### Imperative API

> Import the Loading API and loading.css explicitly for imperative usage.

Call `create()` to show a loading indicator:

```js
const loading = LLoading.create(options);
```

The `options` argument configures the indicator; see the options table below. The returned instance provides a `hide()` method:


```js
  import { transition } from 'utilane/browser';
  //-
  function handleAddTag() {
    if ($tagContainer) {
      let $addTag = document.createElement('l-tag');
      $addTag.setAttribute('closeable', 'true');
      $addTag.setAttribute('type', 'primary');
      $addTag.style.marginRight = "5px";
      $addTag.innerHTML = 'Tag';
      $tagContainer.appendChild($addTag);
      transition($addTag, 'l-scale', "enter");
      $addTag = null;
    }
  }
  //-
  function onClose(e) {
    transition(e.target, 'l-scale', "leave", () => {
      e.target.remove();
    });
  }
  //-
  const $addBtn = document.getElementById('btn-add');
  const $tagContainer = document.getElementById('tag-container');
  $tagContainer.addEventListener('close', onClose);
  $addBtn.addEventListener('click', handleAddTag);
```

An image component with preview, native image attributes, lazy loading, placeholders, and error fallbacks.

## Import and Registration

```js
import {

  RefreshRightIcon,

```

## Examples

### Basic Usage

Set the image URL with `src`, and its dimensions with `width` and `height`.

```html
  <l-image src="https://gw.alipayobjects.com/zos/antfincdn/aPkFc8Sj7n/method-draw-image.svg" width="100px"></l-image>
```

### Object Fit

Set `fit` to control how the image fits its container:

* fill: Stretch the image to fill the content box. Its aspect ratio may change.
* contain: Fit the entire image inside the content box while preserving its aspect ratio; empty space may remain.
* cover: Fill the content box while preserving the aspect ratio, cropping any overflow.
* none: Keep the image at its intrinsic size.
* scale-down: Use the smaller result of none and contain, preserving the aspect ratio without enlarging the image.

```html
  <l-image
    src="/litos-ui/img1.svg"
    width="100px"
    height="100px"
    fit="fill"
  ></l-image>
  <l-image
    src="/litos-ui/img1.svg"
    width="100px"
    height="100px"
    fit="contain"
  ></l-image>
  <l-image
    src="/litos-ui/img1.svg"
    width="100px"
    height="100px"
    fit="cover"
  ></l-image>
  <l-image
    src="/litos-ui/img1.svg"
    width="100px"
    height="100px"
    fit="none"
  ></l-image>
  <l-image
    src="/litos-ui/img1.svg"
    width="100px"
    height="100px"
    fit="scale-down"
  ></l-image>
```

### Placeholder

Set `placeholder` to an image displayed while the main image loads. For progressive loading of large images, use a blurred version of the original.

```html
  <l-image src="/litos-ui/img1.svg" width="100px" placeholder="/litos-ui/img_loading.png"></l-image>
```

### Error Fallback

Set `fallback` to an image URL displayed on failure. To provide custom fallback content, enable `custom-fallback` and use the `fallback` slot.

```html
  <l-image src="/litos-ui/img3.svg" width="100px" height="100px" fallback="/litos-ui/loading_error.png"></l-image>
  <l-image src="/litos-ui/img3.svg" width="100px" height="100px" custom-fallback>
    <span slot="fallback">error</span>
  </l-image>
```

### Multiple-image Preview

Call `setPreviewImageList(imageList?: string[])` to supply the preview images, and set `preview-index` to choose the initial image.

```html
  <l-image class="morePreview" src="/litos-ui/img1.svg" width="100px" preview-index="0"></l-image>
  <l-image class="morePreview" src="/litos-ui/img2.svg" width="100px" preview-index="1"></l-image>
  <l-image class="morePreview" src="https://gw.alipayobjects.com/zos/antfincdn/aPkFc8Sj7n/method-draw-image.svg" width="100px" preview-index="2"></l-image>
```

```js
  import { $, $$, on, off, iterate } from 'utilane/browser';
  const imgs = [
    '/litos-ui/img1.svg',
    '/litos-ui/img2.svg',

    item.setPreviewImageList(imgs);
  });
```

### Disabling Preview


### Manual Preview

Use `ImagePreview` directly to preview images without relying on the `Image` component.

```html
  <l-image
    class="customPreview"
    src="/litos-ui/img1.svg"
    width="100px"
    data-preview-index="0"
    preview-disabled
  ></l-image>
  <l-image
    class="customPreview"
    src="/litos-ui/img2.svg"
    width="100px"
    data-preview-index="1"
    preview-disabled
  ></l-image>
  <l-image
    class="customPreview"
    src="https://gw.alipayobjects.com/zos/antfincdn/aPkFc8Sj7n/method-draw-image.svg"
    width="100px"
    data-preview-index="2"
    preview-disabled
  ></l-image>
```

```js
  import { $, $$, on, off, iterate } from 'utilane/browser';
  const imgs = [
    '/litos-ui/img1.svg',
    '/litos-ui/img2.svg',
    'https://gw.alipayobjects.com/zos/antfincdn/aPkFc8Sj7n/method-draw-image.svg'
  ];
  let $preview;
  const $customPreview = $('.customPreview');
  iterate($customPreview, (item) => {
    on(item, 'click', handleCustomTap);
  });
  function handleCustomTap(e) {
    const index = Number(e.target.getAttribute('data-preview-index'));
    if (!$preview) {
      $preview = $$("l-image-preview");
      $preview.setImages(imgs);
      $preview.setCurrentIndex(index);
      on($preview, 'closed', handlePreviewClosed);
      document.body.appendChild($preview);
      $preview.open = true;
    }
  }
  function handlePreviewClosed() {
    if ($preview) {
      off($preview, 'closed', handlePreviewClosed);
      $preview.remove();
      $preview = undefined;
    }
  }
```

Weekday labels support Chinese and English. These examples use `locale="en-US"`; the week starts on Monday in both languages.

## Examples

### Basic Usage

Set `year` and `month` to display a specific month. The current year and month are used by default.

```html
  <l-calendar locale="en-US" year="2026" month="2"></l-calendar>
```

### Date Limits

Use `min-date` and `max-date` to limit the selectable dates.

```html
  <l-calendar locale="en-US" min-date="2026-03-20" max-date="2026-03-25"></l-calendar>
```

### Changing the Month

Handle `day-click` to obtain the clicked date and change the displayed month when a date from an adjacent month is clicked.

```html
  <l-calendar locale="en-US" id="calendar1"></l-calendar>
```

### Selected Dates

Use `type="select"` and set `value` to select dates.

```html
  <l-calendar locale="en-US" id="calendar2"></l-calendar>
```

```js
  const $calendar2 = $one('#calendar2');
  const selectedDates = [];
  //-
  function handleDayClick2(e) {
    const detail = e.detail;
    let i = selectedDates.indexOf(detail.day);
    if (i !== -1) {
      selectedDates.splice(i, 1);
    } else {
      selectedDates.push(detail.day);
    }
    $calendar2.value = selectedDates.join("&");
  }
  //-
  on($calendar2, 'day-click', handleDayClick2);
```

> Separate dates in `value` with `&` to select multiple dates.

### Range Selection

Use `type="range"` and set `value` to two timestamps in `number,number` format to select a date range.

```html
  <l-calendar locale="en-US" id="calendar3" type="range"></l-calendar>
```

```js
  const $calendar3 = $one('#calendar3');
  let startRangeSelect = false;
  let rangeDate = [];
  //-
  function updateRangeEnd(endDate) {
    rangeDate[1] = endDate;
    if (rangeDate[0] > rangeDate[1]) {
      const temp = rangeDate[0];
      rangeDate[0] = rangeDate[1];
      rangeDate[1] = temp;
    }
  }
  //-
  function handleDayClick3(e) {
    const detail = e.detail;
    if (!startRangeSelect) {
      startRangeSelect = true;
      rangeDate = [detail.dayTimestamp, detail.dayTimestamp];
    } else {
      updateRangeEnd(detail.dayTimestamp);
      startRangeSelect = false;
    }
    $calendar3.value = rangeDate.join(",");
  }
  //-
  function handleDayHover(e) {
    if (!startRangeSelect) return;
    const detail = e.detail;
    updateRangeEnd(detail.dayTimestamp);
    $calendar3.value = rangeDate.join(",");
  }
  //-
  on($calendar3, 'day-click', handleDayClick3);
  on($calendar3, 'day-hover', handleDayHover);
```

## Locale Resolution

`getLocale()` reads an explicit argument, sessionStorage, localStorage, `html.lang`, browser languages, then falls back to `zh-CN`. Both storage sources use the `locale` key with plain language strings; JSON and legacy cache formats are not parsed. Reading blocked storage is safe. The utility returns a language identifier; Calendar maps it to supported labels.

```js
import { getLocale } from "utilane/browser";
localStorage.setItem("locale", "en-US");
const locale = getLocale();
```

Changing the locale attribute updates an existing Calendar. Removing it reads the current environment again. Changing storage or html.lang alone does not automatically update mounted components; set their locale attributes when switching language.

```js
import { Message } from "litos-ui";
```


```js
  import { Message } from 'litos-ui';
  import { elem, on } from 'utilane/browser';
```

### Message Types

Provide success, warning, informational, and error feedback.

Pass an options object to customize more settings. Set `type` to select the message type (the default is `info`) and `message` to supply its content. Each type also has a convenience method, such as `Message.info('x')`, so you do not need to specify `type` explicitly.

```js
  import { Message } from 'litos-ui';

  Message.info("Informational message");

  Message.error("Error message");
```

### Closing Manually

Set `duration` to `0` to prevent automatic closing. The show method returns a message `id`; pass it to `Message.close()` to close the message manually.

```js
  import { Message } from 'litos-ui';

  const id = Message.show({
    message: 'This message must be closed manually',
    type: 'info',
    duration: 0
```

# Notification

Notifications pushed by the system. Compared with [Message](https://dvshu.github.io/litos-ui/en/components/message.md), Notification is better suited to:

1. More complex notification content
2. Interactive notifications that offer a next action
3. System-initiated notifications

The component provides four types: `info`, `success`, `error`, and `warning`. Notifications can appear in any of the four corners. Notifications in the same corner are arranged without overlapping, with animations when they are inserted or repositioned.

## Import and Registration

```js
import {
  Notification,
  NotificationBox,
  regist,
  InfoIcon,
  SuccessIcon,
  WarnIcon,
  CloseFilledIcon,
  CloseIcon,
} from "litos-ui";
import "litos-ui/styles/notification.css";

regist([InfoIcon, SuccessIcon, WarnIcon, CloseFilledIcon, CloseIcon, Notification]);
```

> Register Notification and the required icons explicitly before declarative or imperative usage. NotificationBox does not register elements automatically.

## Basic Usage

### Declarative Usage

Click the buttons below to show the examples; no notifications open automatically on page entry.

Control visibility with `open`, set the heading with `title`, and set the content with `message`. Declarative notifications do not close automatically by default (`duration` is `0`); visibility is controlled by `open`.

```html
  <l-button id="show-notification-basic" data-notification="component" data-target="notification-basic">Show component notification</l-button>
  <l-notification id="notification-basic"
    title="System notification"
    message="A notification from the system. Close it using the button in the top-right corner."
  ></l-notification>
```

```js
  document.getElementById('show-notification-basic').addEventListener('click', (event) => {
    document.getElementById(event.currentTarget.getAttribute('data-target')).show();
  });
```

For declarative usage, customize content with the `title`, `default`, and `action` slots.

```html
  <l-button id="show-notification-slots" data-notification="component" data-target="notification-slots">Show custom notification</l-button>
  <l-notification id="notification-slots" type="info" duration="0">
    <span slot="title">Custom title</span>
    <div>
      <p>First line of content</p>
      <p>Second line of content</p>
    </div>
  </l-notification>
```

```js
  document.getElementById('show-notification-slots').addEventListener('click', (event) => {
    document.getElementById(event.currentTarget.getAttribute('data-target')).show();
  });
```

### Imperative Usage

Call a static method on `Notification` to show a notification from your code. The method returns its `id`.

```html
  <l-button>Show notification</l-button>
```

```js
  import { NotificationBox } from 'litos-ui';
  import { elem, on } from 'utilane/browser';
  //-
  on(elem('l-button')[0], 'click', () => {
    NotificationBox.show({
      title: 'Notification title',
      message: 'This notification closes automatically after 4.5 seconds.',
    });
  });
```

### Notification Types

Set `type` to `info`, `success`, `error`, or `warning`. Each type has a convenience method, so you can call it without supplying `type`, for example `NotificationBox.success('Saved successfully')`.

```js
  import { NotificationBox } from 'litos-ui';
  //-
  NotificationBox.info({ title: 'Information', message: 'This is an informational message.' });
  NotificationBox.success({ title: 'Success', message: 'Data saved successfully.' });
  NotificationBox.warning({ title: 'Warning', message: 'This operation may involve a risk.' });
  NotificationBox.error({ title: 'Error', message: 'The request failed. Please try again later.' });
```

### Placement

Set `placement` to `topLeft`, `topRight`, `bottomLeft`, or `bottomRight`. Notifications in the same corner do not overlap; existing notifications reposition automatically.

```js
  import { NotificationBox } from 'litos-ui';
  //-
  NotificationBox.info({ title: 'Top left', message: 'A message from the top-left corner.', placement: 'topLeft' });
  NotificationBox.info({ title: 'Top right', message: 'A message from the top-right corner.', placement: 'topRight' });
  NotificationBox.info({ title: 'Bottom left', message: 'A message from the bottom-left corner.', placement: 'bottomLeft' });
  NotificationBox.info({ title: 'Bottom right', message: 'A message from the bottom-right corner.', placement: 'bottomRight' });
```

> Click the same button repeatedly to see notifications arrange themselves in the same corner without covering one another.

### Complex Content

Pass an HTML string as `message` to display more complex content.

```js
  import { NotificationBox } from 'litos-ui';
  //-
  NotificationBox.success({
    title: 'Deployment complete',
    message: '<div>Branch: <b>main</b></div><div>Duration: 32s</div>',
  });
```

### Actions

Set the action button text with `action`. Clicking it emits an `action` event so you can handle the next step. For imperative usage, supply an `onAction` callback.

```js
  import { NotificationBox } from 'litos-ui';
  //-
  NotificationBox.warning({
    title: 'New version available',
    message: 'The new version fixes several issues. We recommend updating now.',
    action: 'Update now',
    duration: 0,
    onAction: (id) => {
      // Handle the next user action.
      console.log('Action clicked', id);
    },
  });
```

### Automatic and Manual Closing

Set `duration` to the auto-close delay in milliseconds, or `0` to disable automatic closing. The countdown pauses while the pointer is over the notification and resumes when it leaves. Show methods return an `id`; call `NotificationBox.close(id)` to close that notification manually.

```js
  import { NotificationBox } from 'litos-ui';
  //-
  // Show a notification and save its id.
  const id = NotificationBox.error({
    title: 'Close manually',
    message: 'This notification will not close automatically.',
    duration: 0,
  });
  // Close the specified notification.
  NotificationBox.close(id);
  // Close all notifications.
  NotificationBox.closeAll();
```

### Global Configuration

Set global defaults with `NotificationBox.config`. Notifications created afterward use those defaults.

```js
  import { NotificationBox } from 'litos-ui';
  //-
  NotificationBox.config({
    width: 380,
    duration: 6000,
    maxCount: 3,
  });
  NotificationBox.info({ title: 'Global configuration', message: 'This notification uses the global width and duration settings.' });
```

> Global configuration remains in effect and accepts all options, including `placement`, `width`, `duration`, `offset`, `zIndex`, and `maxCount`. The configuration code above is for reference; the live button does not apply global configuration, to avoid affecting other examples.

# Popover

Show a floating card when an element is clicked or hovered. Unlike a tooltip, a popover can contain interactive elements such as links and buttons, making it suitable for more complex content.

## Import and Registration

```js
import { Popover, regist, Button, WarnIcon } from "litos-ui";
import "litos-ui/styles/popover.css";
regist([Button, WarnIcon]); // Register Button and WarnIcon when using Popconfirm.

const popover = new Popover();

// On unmount, call popover.destroy().
```

## Examples

### Basic Usage

Add a `data-title` attribute and the `l-popover-reference` class to the trigger element, then create a `Popover` instance.

```html
  <a data-title="Hover hint" class="l-popover-reference">Hint</a>
```

```js
  let popover = new Popover();
  // On unmount, call popover.destroy().
```

> Pass `reference` to specify the reference elements when constructing `Popover`. If omitted, it finds all `.l-popover-reference` elements.

### Triggers

Set `trigger` to `hover`, `click`, or `focus`. The default is `hover`.

```html
  <l-button id="hover-popover" data-title="Hover hint">Hover hint</l-button>
  <l-button id="click-popover" data-title="Click hint">Click hint</l-button>
  <l-button id="focus-popover" data-title="Focus hint">Focus hint</l-button>
```

```js
  new Popover({
    reference: '#hover-popover',
    trigger: 'hover',
  });
  new Popover({
    reference: '#click-popover',
    trigger: 'click',
  });
  new Popover({
    reference: '#focus-popover',
    trigger: 'focus',
  });
```

> Set `trigger: "manual"` for manual control, then call `popover.show(reference)` and `popover.hide()`. The separate `updatePosition` and `autoUpdate` helpers handle positioning rather than visibility.

```html
    <l-button class="l-popover-reference" data-title="Hint content" data-placement="left-end">left-end</l-button>
```

Set `arrow` to `false` when constructing `Popover` to hide the arrow. Use `offset` to adjust the distance from the reference element.

### Custom Content

Customize content with `contentRender` and `updateContent`, or supply a custom DOM element through the `popover` option.

```html
  <l-button id="custom">Hint</l-button>
```

```js
  new Popover({

  })
```

```js [js]
const $popover = document.querySelector("#popover");

  reference: "#custom",
```

### Dynamic List Elements

Use `createPopoverObserver` to track elements added to or removed from a dynamic list, such as when changing pages.

```html
  <l-button id="addTag" type="primary">Add tag</l-button>
  <hr />
  <div id="tagGroup"></div>
```

```js
  import { createPopoverObserver, Popover, Tag, Button, CloseIcon, regist } from 'litos-ui';
  import 'litos-ui/styles/transition.css';
  regist([CloseIcon, Button, Tag]);
  import { transition } from 'utilane/browser';
  //-
  let $tagGroup = document.getElementById('tagGroup');
  let $addTag = document.getElementById('addTag');
  //-
  let tooltip = new Popover({
    reference: '.tooltip-tag',
    theme: 'tooltip',
  });
  //-
  let observer = createPopoverObserver(tagGroup, 'tooltip-tag', tooltip);
  //-
  function handleAddTag() {
    if ($tagGroup) {
      let $addTagTmp = document.createElement('l-tag');
      $addTagTmp.setAttribute('closeable', 'true');
      $addTagTmp.setAttribute('type', 'primary');
      $addTagTmp.setAttribute('data-title', 'Tag tooltip'); // Set the tooltip content.
      $addTagTmp.style.marginRight = "5px";
      $addTagTmp.classList.add('tooltip-tag'); // Add the tooltip-tag class.
      $addTagTmp.innerHTML = 'Tag';
      $tagGroup.appendChild($addTagTmp);
      transition($addTagTmp, 'l-scale', "enter");
      $addTagTmp = null;
    }
  }
  //-
  function handleRemoveTag(e) {
    transition(e.target, 'l-scale', "leave", () => {
      e.target.remove();
    });
  }
  //-
  $addTag.addEventListener('click', handleAddTag);
  $tagGroup.addEventListener('close', handleRemoveTag);
  //-
  // Release resources on unmount.
  // tooltip.destroy();
  // observer.disconnect();
  // tooltip = null;
  // observer = null;
  // $addTag.removeEventListener('click', handleAddTag);
  // $tagGroup.removeEventListener('close', handleRemoveTag);
```

`createPopoverObserver(target: HTMLElement,class: string,popover: Popover): MutationObserver`

Creates an observer that updates the popover references when elements with the specified class are added or removed.

1. `target`: The element whose children are observed, typically a list container or table.
2. `class`: The class used to identify relevant added or removed elements.
3. `popover`: The Popover instance whose references are updated when matching elements change.

> For a small, fixed set of elements, call `popover.addReference` and `popover.removeReference` manually instead of using `createPopoverObserver`.

# Dialog

Display a dialog while preserving the current page state. It contains a header, content area, and action area.

## Import and Registration

```js
import {
  DialogContainer,
  regist,
  Button,
  CloseIcon,
  Dialog,
  DialogBox,
  LoadingIcon,
} from "litos-ui";
import "litos-ui/styles/dialog.css";

regist([CloseIcon, LoadingIcon, Button, DialogContainer]);
```

## Examples

### Basic Usage

Place `l-dialog-container` inside a native `dialog` element and set its `header` attribute to the title.

The container supports `cancel-text` and `ok-text` for button labels. Their built-in defaults and the DialogBox service labels remain in Chinese; this page does not change component localization.

```html
  <dialog id="dialog">
    <l-dialog-container header="Title">
      <div>This is a dialog example.</div>
    </l-dialog-container>
  </dialog>
```

```js
  const dialog = new Dialog({
    el: '#dialog',
    onAction: (action, done) => {
      console.log(action);
      done();
    }
  });
  dialog.open(); // Open the dialog.
  // On unmount, call dialog.destroy() to release listeners.
```

> Call `dialog.destroy()` when the page unmounts, for example in `onUnmounted`, to release its listeners.

### Custom Header

Instead of setting the `header` attribute, use the `header` slot for custom content, such as a confirmation icon. Set `width` on the native dialog element to change its width.

```html
  <dialog id="dialog" width="300px">
    <l-dialog-container>
      <l-info-icon slot="header"></l-info-icon>
      <span slot="header">Header</span>
      <div>This is a dialog example.</div>
    </l-dialog-container>
  </dialog>
```

```js
  const dialog = new Dialog({
    el: '#dialog',
    onAction: (action, done) => {
      done();
    }
  });
  dialog.open(); // Open the dialog.
  // On unmount, call dialog.destroy() to release listeners.
```

### Mobile Style

Set `mobile` on `l-dialog-container` for a mobile-style dialog with a centered title and evenly arranged footer buttons.

```html
  <dialog id="dialog" vertical-align="middle">
    <l-dialog-container header="Notice" mobile>
      <div>This is a mobile-style dialog example.</div>
    </l-dialog-container>
  </dialog>
```

```js
  const dialog = new Dialog({
    el: '#dialog',
    onAction: (action, done) => {
      console.log(action);
      done();
    }
  });
  dialog.open(); // Open the dialog.
  // On unmount, call dialog.destroy() to release listeners.
```

### Asynchronous Closing

Close the dialog asynchronously after confirmation, for example after submitting a form. Use `confirm-loading` for the confirmation button's loading state and handle the asynchronous operation in `onAction`.

```html
  <dialog id="dialog">
    <l-dialog-container header="Asynchronous closing">
      <div>Dialog content</div>
    </l-dialog-container>
  </dialog>
```

```js
  const dialog = new Dialog({
    el: '#dialog',
    onAction: (action, done) => {
      if (action === 'ok') {
        const $container = document.querySelector('#dialog l-dialog-container');
        // Enable confirmation button loading.
        $container.setAttribute('confirm-loading', '');
        // Simulate an asynchronous operation.
        setTimeout(() => {
          // Remove loading and close the dialog.
          $container.removeAttribute('confirm-loading');
          done();
        }, 1500);
      } else {
        done();
      }
    }
  });
  dialog.open();
  // On unmount, call dialog.destroy().
```

> While `confirm-loading` is enabled, clicking the confirmation button does not call `onAction` again, preventing duplicate submissions.

### Message Boxes

Message boxes provide styled alternatives to native browser dialogs for alerts, confirmations, and text input. The three methods are `alert`, `confirm`, and `prompt`.

Call `DialogBox.alert()`, `DialogBox.confirm()`, or `DialogBox.prompt()`.

```js
  import { DialogBox } from "litos-ui";
  // alert
  DialogBox.alert('This is some content', 'Title').then(() => {
    console.log("alert close")
  });
  // confirm
  DialogBox.confirm('Save your changes?', 'Notice').then((ok) => {
    console.log(ok);
  })
  // prompt
  DialogBox.prompt('Command key', 'Command', { placeholder: 'Enter a command' }).then((text) => {
    console.log(text);
  });
```

### Dialog

`Dialog` is a class for controlling a native `<dialog>` element, used with the `l-dialog-container` Web Component.

#### Constructor

```text
new Dialog(option?: DialogInitialParams)
```

#### DialogInitialParams

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| el | `HTMLDialogElement \| string` | - | **Required**: dialog element or CSS selector |
| onAction | `(action: string, done: () => void) => void` | - | Button callback; action is ok, cancel, or close. Call done() to close the dialog |

| Method | Description |
| --- | --- |
| `open()` | Opens the dialog |
| `close()` | Closes the dialog |
| `destroy()` | Removes event listeners; call when the page unmounts |
| `setProp(key, value)` | Sets a single property |
| `setProps(props)` | Sets multiple properties |
| `setConfirmLoading(loading)` | Sets the confirmation button loading state |

`Dialog` reads the following HTML attributes from the native `<dialog>` element during initialization. Attribute values take precedence over JavaScript configuration:

* `vertical-align`
* `translate`
* `width`
* `close`

### Message Boxes

Modal message boxes provide styled alternatives to the native browser `alert`, `confirm`, and `prompt` dialogs for alerts, confirmations, and text input.

Call `ModalBox.alert()`, `ModalBox.confirm()`, or `ModalBox.prompt()`.

```js
  // alert
  ModalBox.alert('This is some content', 'Title').then(() => {
    console.log("alert close")
  });
  // confirm
  ModalBox.confirm('Save your changes?', 'Notice').then((ok) => {
    console.log(ok);
  })
  // prompt
  ModalBox.prompt('Command', 'Command key', { placeholder: 'Enter a command' }).then((text) => {
    console.log(text);
  });
```

# Dropdown

通过 `reference` 为已有元素绑定操作菜单，复用 Popover 的显示、悬停和视口边界定位。

## 引入

```js
import { createDropdown } from "litos-ui/dropdown";
import "litos-ui/styles/vars.css";
import "litos-ui/styles/popover.css";
import "litos-ui/styles/dropdown.css";
```

这是函数 API，无需注册自定义元素。SSR 项目在客户端挂载后调用；暗黑模式按需引入 `litos-ui/styles/dark.css`。

## 基础用法与选择反馈

将已有元素传入 `reference`，通过 `items` 配置菜单。`onSelect` 接收选中项和实际触发元素。

```html
<button id="dropdown-basic" type="button"><span>更多操作 ▾</span></button>
<output id="dropdown-result" aria-live="polite">请选择操作</output>
```

```js
const menu = createDropdown({
  reference: document.querySelector("#dropdown-basic"),
  trigger: "click",
  items: [
    { key: "edit", label: "编辑" },
    { key: "copy", label: "复制", disabled: true },
    { key: "separator", label: "", divider: true },
    { key: "delete", label: "删除", danger: true },
  ],
  onSelect: ({ key, reference }) => console.log(key, reference),
});
// 页面卸载时清理
menu.destroy();
```

## 悬停与多个触发元素

`reference` 支持元素、元素数组或选择器；多个元素可以共用一个菜单。使用 `trigger: "hover"` 通过鼠标悬停展开。

```html
<button class="dropdown-shared" type="button">悬停入口 A</button>
<button class="dropdown-shared" type="button">悬停入口 B</button>
```

```js
const menu = createDropdown({
  reference: ".dropdown-shared",
  trigger: "hover",
  placement: "bottom-end",
  items: [{ key: "view", label: "查看" }],
});
```

## 更新与禁用

使用 `setItems()` 更新选项，`show()` 和 `hide()` 控制显示；禁用状态下不会展开。

```html
<button id="dropdown-dynamic" type="button">动态菜单</button>
<button type="button" data-dropdown-update>更新选项并展开</button>
<button type="button" data-dropdown-disable>切换禁用状态</button>
<output id="dropdown-disabled" aria-live="polite">可用</output>
```

```js
menu.setItems([{ key: "refresh", label: "刷新" }]);
menu.show();
menu.setDisabled(true);
menu.setDisabled(false);
menu.hide();
```

## 自定义内容

省略 `items`，通过 `content` 传入 DOM 内容，可复用已有菜单。其交互事件由调用方绑定，`onSelect` 只用于 `items` 生成的菜单。

```js
const menu = createDropdown({
  reference: triggerElement,
  content: customMenuElement,
  trigger: "click",
});
```

## API

### DropdownOptions

| 选项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `reference` | `HTMLElement \| HTMLElement[] \| string` | 必填 | 触发元素，选择器在创建时解析；不存在时抛出 `TypeError` |
| `items` | `DropdownItem[]` | `[]` | 菜单项，传入时优先于 `content` |
| `content` | `HTMLElement` | — | 自定义内容，原位置在销毁时恢复 |
| `trigger` | `"click" \| "hover" \| "manual"` | `"click"` | 交由 Popover 处理触发方式 |
| `placement` | `DropdownPlacement` | `"bottom-start"` | 上下定位各支持 `start`、居中、`end`，空间不足时调整方向 |
| `disabled` | `boolean` | `false` | 是否禁用 |
| `closeOnSelect` | `boolean` | `true` | 用户选择后是否关闭 |
| `onSelect` | `(detail) => void` | — | `detail` 为 `{ key, item, index, reference }`，禁用项与分隔线不触发 |
| `onOpenChange` | `(open: boolean) => void` | — | 实际展开状态变化，包括程序控制 |

### DropdownItem

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `key` | `string` | 操作标识 |
| `label` | `string` | 纯文本菜单文字 |
| `disabled` | `boolean` | 禁用此项，默认 `false` |
| `danger` | `boolean` | 使用错误状态色，默认 `false` |
| `divider` | `boolean` | 分隔线，不显示文字，默认 `false` |

### 返回实例

| 成员 | 说明 |
| --- | --- |
| `show(reference?)` | 默认对齐首个触发元素；参数必须属于创建时的 `reference` 集合 |
| `hide()` | 关闭菜单 |
| `isOpen()` | 返回是否展开 |
| `setItems(items)` | 替换选项并重建菜单，更新后的菜单替代自定义内容 |
| `setDisabled(disabled)` | 修改禁用状态；禁用时关闭 |
| `destroy()` | 清理监听器、定位 Observer 和菜单节点；可重复调用 |
| `menu` | 菜单容器 DOM，便于调整样式 |
| `popover` | 底层 Popover 实例 |

`DropdownPlacement` 为 `bottom-start`、`bottom`、`bottom-end`、`top-start`、`top`、`top-end`。

### CSS 变量

| CSS 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `--l-dropdown-min-width` | `160px` | 菜单最小宽度 |
| `--l-dropdown-max-height` | `min(320px, 60vh)` | 菜单最大高度 |
| `--l-dropdown-background` | `var(--l-fill-secondary-color, #fff)` | 背景 |
| `--l-dropdown-hover-background` | `var(--l-primary-color-light5, #e6f2ff)` | 普通项悬停背景 |
| `--l-dropdown-shadow` | `0 6px 24px #0002` | 阴影 |

菜单挂载在 `body`，局部定制可通过返回实例的 `menu.style` 设置变量；不会继承触发元素所在局部容器的变量。

## 使用限制

当前为平铺操作菜单，不提供方向键导航、Escape 焦点恢复或子菜单。点击触发区外关闭菜单；悬停适用于鼠标，触摸设备建议使用 `click`。不依赖原生 Popover API，但本页未进行 iOS 16 真机验证。触发元素移除或页面卸载时需要调用 `destroy()`；新增触发元素需重新创建实例。

# DescriptionPanel

Display descriptions or introductory text, especially on mobile screens where space is limited and only a small amount of content is shown initially.

## Import and Registration

```js
import { DescriptionPanel, regist, Button, ArrowDownIcon } from "litos-ui";

regist([ArrowDownIcon, Button, DescriptionPanel]);
```

## Examples

### Basic Usage

All block-level content in the content area inherits a `text-indent`.

The sample article below is translated from the Chinese documentation. The component's built-in expand/collapse button currently uses Chinese labels; component localization is separate from this page's translation.

```html
  <l-description-panel>
    <p>Chery recently announced plans for a strategic partnership with Jaguar Land Rover, whose new product line will be built on Chery's electric vehicle platform. Meanwhile, Dongfeng Nissan's Yunfeng plant has chosen to manufacture a new electric SUV for Voyah. One foreign brand is seeking contract production from a domestic brand, while the other is manufacturing for a domestic brand. Both are focused on reducing costs.</p>
    <p>Looking further back, cost reduction also led two major joint-venture automakers, FAW-Volkswagen and GAC Honda, to the same response: job cuts. This suggests that joint-venture brands, once dominant, have entered their most difficult period. The release of May sales figures, showing their market share falling to 28.8%, made the seriousness of their position in China even clearer to the public.</p>
    <p>Although joint-venture brands have visibly struggled with the shift toward electric and intelligent vehicles, the scale of their decline in recent years has still surprised many industry observers. During this near free fall, what exactly did these brands get wrong? Do they still have a chance to recover?</p>

  </l-description-panel>
```
