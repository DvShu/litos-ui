原生组件

基于原生 Web Components 构建，使用自定义元素与 Shadow DOM，可在支持相关能力的浏览器中运行。

📦

npm 安装

通过 npm 安装 litos-ui，使用 ESM 导入所需组件，并通过 regist 注册后使用。

🎨

主题定制

使用 CSS 变量调整配色，提供翡翠绿、珊瑚红和活力橙预置主题，并支持暗黑模式。

🛠️

样式扩展

通过组件提供的 CSS 变量与 part 定制样式，按组件文档选择对应的扩展入口。

📝

TypeScript

组件使用 TypeScript 编写，发布包包含类型声明，便于在开发时查看 API 与类型提示。

🌐

浏览器环境

依赖 Custom Elements、Shadow DOM 和可构造样式表等浏览器 API；服务端渲染项目需在客户端导入和注册组件。
