Getting Started
GitHub
🧩

Native Components

Built with native Web Components, using Custom Elements and Shadow DOM. Runs in browsers that support these APIs.

📦

Installation

Install litos-ui from npm, import the components you need with ESM, and register them with regist.

🎨

Theming

Customize colors with CSS variables. Choose from the Jade, Coral, and Tangerine presets, with support for dark mode.

🛠️

Styling

Customize components with CSS variables and CSS parts. See each component's documentation for its styling options.

📝

TypeScript

Written in TypeScript, with type declarations included in the package for API discovery and type hints during development.

🌐

Browser Environment

Requires browser APIs such as Custom Elements, Shadow DOM, and constructable stylesheets. In server-rendered applications, import and register components on the client.
